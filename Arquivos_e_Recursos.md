# Arquivos E Recursos Do Repositório

## Objetivo desta página

Esta página resume o que existe no repositório e para que serve cada grupo de arquivos. A ideia é facilitar o uso deste projeto como uma wiki pública.

## Como usar este repositório

Se o objetivo for entender o projeto como um todo, a melhor sequência é:

1. começar por [README.md](README.md);
2. seguir para [Projeto.md](Projeto.md);
3. consultar as páginas específicas de mecânica, firmware, eletrônica e app;
4. usar [Galeria.md](Galeria.md) para apoio visual;
5. abrir o `Relatório.pdf` para a versão acadêmica consolidada.
